# 💱 Currency Converter

A responsive Currency Converter web application built using **HTML, CSS, and JavaScript**.  
This project allows users to convert currencies with real-time exchange rates fetched from an API while providing a clean and user-friendly interface.

## 🚀 Features

- Convert between multiple currencies
- Fetch live exchange rates using API
- Real-time currency conversion
- Swap currencies functionality
- Responsive design for desktop, tablet, and mobile devices
- Clean and modern user interface
- User-friendly input experience

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Exchange Rate API

## 🧠 Problem Solving Approach

- Implemented API integration to fetch updated exchange rates.
- Handled user inputs and currency selections dynamically.
- Created responsive layouts to ensure a smooth experience across different screen sizes.
- Added interactive features to improve usability.
